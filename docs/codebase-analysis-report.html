React act() warnings in tests

Severity: Low | Confidence: High

Effort: Medium (1-5 days)

Several tests show React warnings about state updates not being wrapped in act(). This affects test reliability and indicates potential timing issues.

Files: src/components/__tests__/DragDropProvider.ios.test.tsx, src/components/__tests__/KanbanBoard.test.tsx

Recommendation: Wrap state updates in tests with act() to ensure proper React testing practices.

import { act } from '@react-testing-library/react';

await act(async () => {
  // fire events that update state
  fireEvent.click(button);
});

Cross-browser E2E testing limited to Chromium

Severity: Medium | Confidence: High

Effort: Small (under 1 day)

E2E tests only run on Chromium. Firefox and WebKit are not configured in playwright.config.ts, missing potential cross-browser issues.

File: playwright.config.ts

Recommendation: Add Firefox and WebKit projects to the Playwright configuration to catch cross-browser compatibility issues early.

projects: [
  { name: 'chromium', use: devices['Desktop Chrome'] },
  { name: 'firefox', use: devices['Desktop Firefox'] },
  { name: 'webkit', use: devices['Desktop Safari'] },
]
